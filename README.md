# AI Resume Analyzer

A console-based AI Resume Analyzer developed using Python.

## Features
- Matches resume skills with required skills
- Displays matched skills
- Displays missing skills
- Calculates resume score percentage

## Technologies Used
- Python

## How to Run

```bash
python resume_analyser.py
```

## Sample Input
python, java, sql

## Sample Output

Matched Skills:
python

Missing Skills:
java
sql

Resume Score: 33%

## Project Objective
This project helps analyze user resume skills and compares them with required job skills.
